Учебный проект — сканер безопасности веб-сайтов (МЭИ, Проектная деятельность).

## Что проверяет

- Открытые порты (80, 443, 22, 3306, 8080)
- SSL-сертификат (валидность, срок действия, издатель)
- HTTP-заголовки безопасности (CSP, X-Frame-Options, HSTS, X-Content-Type-Options)
- Версию веб-сервера

## Стек

- Node.js + Express (бэкенд)
- Vanilla JavaScript + CSS (фронтенд)
- GitHub Actions (CI)

## Запуск

```bash
npm install
npm start
```

Открыть: http://localhost:3000

### Переменные окружения

Создай файл `.env` в корне проекта (на основе `.env.example`):

```bash
cp .env.example .env
```

Доступные переменные:

| Переменная | Значение по умолчанию | Описание |
|---|---|---|
| `PORT` | `3000` | Порт, на котором запускается сервер |
| `DEMO_MODE` | `false` | Разрешает сканирование `localhost` (только для демонстрации) |

**Важно:** настоящий `.env` не попадает в Git — он добавлен в `.gitignore`.

### Режим демонстрации

Для локальной демонстрации на `localhost` (тестовый стенд) используется переменная окружения:

```bash
DEMO_MODE=true NODE_ENV=development npm start
```

В этом режиме разрешено сканирование `localhost` — для показа работы сканера на тестовом стенде.

**В продакшене `DEMO_MODE` не включается** — внутренние адреса остаются заблокированными.

## Безопасность и ограничения

Сервис имеет встроенные ограничения для предотвращения misuse:

- **SSRF-защита** — блокировка сканирования внутренних адресов (`127.0.0.1`, `192.168.x.x`, `10.x.x.x`, `169.254.x.x`, CGNAT).
- **Cooldown 10 секунд** на IP — защита от превращения сканера в DDoS-инструмент.
- **Таймаут 30 секунд** на фронте и 3–5 секунд на бэкенде.
- **Обязательное согласие** — проверяется на фронте и бэке.
- **Свежесть согласия** — timestamp действует 5 минут.
- **Валидация домена** через регулярное выражение на бэкенде.
- **Логирование** — каждый запрос пишется в консоль с IP и URL.
- **Никаких эксплуатаций уязвимостей** — сканер только собирает открытую информацию.
